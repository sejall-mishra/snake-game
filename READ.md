# Snake Game

A classic Snake game built with Python and the turtle module.

## Features

- Three difficulty levels: Easy, Medium and Hard
- Score and high score, with the high score saved in a file
- Pause and resume
- The snake cannot reverse into itself
- Game restarts when the snake hits a wall or its own tail

## Controls

| Key | Action |
|---|---|
| Arrow keys | Move the snake |
| 1 | Easy |
| 2 | Medium |
| 3 | Hard |
| Space | Pause / resume |

## How to run

1. Install Python 3
2. Download this project
3. Run: `python snake.py`
